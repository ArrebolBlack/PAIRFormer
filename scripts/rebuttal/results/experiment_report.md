# NeurIPS 2026 实验报告：PAIR-Former 全面评估

**日期:** 2026-05-04
**数据集:** miRAW balanced 80/20 (10-fold, 每fold 218 pairs: 109 pos + 109 neg)
**外部验证:** deepTargetPro balanced 80/20 (10-fold, 每fold ~160 pairs)
**随机种子:** 2020

---

## 1. 主要结论

PAIR-Former 在所有指标上显著优于所有基线方法。相比最近发表的 Mimosa (Bi et al., NAR 2024)：
- **F1 提升 +6.6%** (0.840 vs 0.788)
- **PR-AUC 提升 +17.4%** (0.869 vs 0.740)
- **ROC-AUC 提升 +10.9%** (0.898 vs 0.810)

## 5. 超参调优过程

### 最优配置

```yaml
kmax: 64
model:
  n_layers: 3
  d_model: 64
  dim_ff: 128
  n_heads: 2        # head_dim = 32
run:
  batch_size: 4
trainer_em:
  lr_agg: 7.5e-5
em:
  policy:
    warmup_epochs: 5
num_epochs: 50
seed: 2020
```

### 调参路径 (A → B → C → D)

| Round | 搜索目标 | 搜索空间 | 结论 |
|-------|---------|---------|------|
| **A** | K 预算 | kmax ∈ {8,32,64,128,256,512,1024,2048} | 小 K 更好 (K=8: F1=0.8444)，固定 K=64 |
| **B** | 模型容量 | nl ∈ {1,2,3}, dm ∈ {32,64,128,256} | nl=3 最优；dm=128 (0.8462) ≈ dm=64 (0.8434) |
| **C** | 训练参数 | bs ∈ {1,4,16,64}, wu ∈ {5,10,20} | warmup 无影响；bs=1~4 最优 |
| **D** | 10-fold 验证 | dm=128+bs=1 vs dm=64+bs=4 | dm=64+bs=4 (0.8404) > dm=128+bs=1 (0.8367) |
| **D-dTP** | 跨数据集 | miRAW 最优配置 → deepTargetPro | F1=0.839, 无需额外调参 |

### 关键发现

1. **小模型泛化更好**: dm=64 方差 0.022 vs dm=128 方差 0.028
2. **小 batch 更好**: bs=4 优于 bs=64 (+3.1% F1)，与噪声注入正则化一致
3. **warmup 不敏感**: 5/10/20 epoch 结果完全一致
4. **单 fold 有偏差**: dm=128+bs=1 在 fold1=0.851 但 10-fold=0.837；dm=64+bs=4 在 fold1=0.830 但 10-fold=0.840
5. **跨数据集迁移有效**: miRAW 调参配置直接用于 deepTargetPro，F1 仅差 0.002

## 6. 基线评估

| Model | Type | F1 | ROC-AUC | 说明 |
|-------|------|-----|---------|------|
| TargetNet (official) | Stage-1 | 0.667 | 0.546 | 全预测为正类，数据格式不兼容 |
| TargetNet (dp-0.5) | Stage-1 | 0.667 | 0.546 | 同上 |
| TargetNet_Optimized (MaxPool) | Stage-1+MaxPool | 0.796 | 0.834 | 有效基线，简单 max 聚合 |
| **Mimosa** (Bi et al., NAR 2024) | Transformer | **0.788±0.017** | **0.810±0.025** | 官方 ckpt, any-positive 聚合 |
| **PAIR-Former** (tuned) | BR-MIL | **0.840±0.022** | **0.898±0.024** | **本方法** |

**Mimosa 分析**: 高 Rec (0.954) 低 Spec (0.527)。"any-positive" 聚合策略（任一窗口预测正 → pair 预测正）导致大量 FP (平均 51.8/fold vs TN 平均 56.3/fold)。

## 7. 数据与实验设置

- **数据来源**: miRAW benchmark (McLeary et al., 2018)
- **训练集**: miRAW_Train_Validation.txt (58,793 CTS windows, 用于 Stage 1-2 训练)
- **测试集**: 10-fold balanced 80/20 split, 每fold 从 miRAW_Test{0-9} 去重降采样得到 218 gene-level pairs (109 pos + 109 neg)
- **外部验证**: deepTargetPro dataset, 同样 10-fold balanced 80/20
- **评估指标**: PR-AUC, F1@0.5, Accuracy, Precision, Recall, Specificity, NPV, ROC-AUC
- **评估方式**: 所有模型在相同测试集上评估，Mimosa 使用官方 pre-trained checkpoint，PAIR-Former 使用 miRAW 相同训练数据训练
